# UI catalog

Twenty shipped-product screens worth borrowing from, and one demo front page per reference showing the Docket desk restyled after it with the same information.

- `index.html`: the catalog (open it in a browser; screenshots come from `../refs/`). The same page is published privately at https://claude.ai/artifact/YXkaUpykXETnG4TRKWnKMb with a pick list.
- `demo-data.json`: the shared information every demo renders (queue, selected applicant P08 with five lender offers, pipeline timings, notice, audit log, eval). Generated by the deterministic stub over the real CRS fixtures so the designs can be compared like for like.
